# Finance Hybrid Pro V3

1. Execute `supabase_schema_v3.sql`.
2. No SQL final, atribua `SUPER_ADMIN` ao UID da sua conta.
3. Confirme as variáveis da Vercel: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SECRET_KEY`.
4. Substitua os arquivos no GitHub e faça novo deploy.

Novidades: calendário mensal, análise diária, painel Super Admin, cadastro controlável, criação/suspensão/ativação/exclusão de usuários.
